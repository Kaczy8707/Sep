# SEP TRENER — pakiet przekazania do Claude

Pakiet zawiera 31 fragmentów lekcyjnych oraz 44 pytań ustnych wyodrębnionych z wcześniejszych skryptów G1–G3. Materiał nie jest pełnym ani prawnie zweryfikowanym kursem. Nie traktuj tych tekstów jako oficjalnej bazy pytań.

## Instrukcja
1. Prześlij Claude ten ZIP i poproś o odczyt pliku `PROMPT_DLA_CLAUDE.md`.
2. Poproś o przygotowanie projektu Android Studio w Kotlinie, nie tylko prototypu w przeglądarce.
3. Uruchom projekt na laptopie w Android Studio, a APK zainstaluj na telefonie.
4. W telefonie wybierz dostępny polski głos w ustawieniach TTS.

## Zawartość
- `content_manifest.json`: komplet danych JSON do importu.
- `G1/G2/G3_lessons.json`, `G1/G2/G3_exam.json`: podział na grupy.
- Oryginalne pliki TXT: do porównania po imporcie.
- `PROMPT_DLA_CLAUDE.md`: pełna specyfikacja aplikacji.

Wskazówka: do finalnej publikacji trzeba dodatkowo zweryfikować zakresy świadectw oraz aktualność przepisów i norm. Nie dołączono danych osobowych ze zdjęć.
