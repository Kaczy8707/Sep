# SEP Trener — rozszerzenie treści G1/G2/G3

Ten pakiet jest **działającym rozszerzeniem treści JSON**, nie ukończonym ani certyfikowanym podręcznikiem. Nowe moduły opisują mechanizmy, zagrożenia, przykłady oraz perspektywę E i D. Nie są instrukcją samodzielnego wykonywania prac niebezpiecznych.

## Użycie
Prześlij cały ZIP do Claude i wklej polecenie: „Wykonaj instrukcję z PROMPT_DLA_CLAUDE.md na istniejącym projekcie SEP Trener, zachowaj postępy i zbuduj APK”.

## Uwaga o danych
G1 01–21 są bez zmian z dostarczonego rozszerzenia. G2 i G3 01–10 pochodzą z pierwotnej paczki. Pytania G1 już obecne w aplikacji muszą pozostać: pakiet zawiera **wyłącznie nowe** pytania G1, a nie kopię starszej bazy.
